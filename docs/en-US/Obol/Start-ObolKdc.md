# Start-ObolKdc

## SYNOPSIS

Starts an Obol Kerberos KDC.

## SYNTAX

### __AllParameterSets

```
Start-ObolKdc [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Outputs a string describing the Obol module and the version of Kerberos.NET it uses.
This is a placeholder cmdlet used to validate the module structure.

## EXAMPLES

### Example 1: Start the KDC

```powershell
PS C:\> Start-ObolKdc
```

Outputs the Obol information string.
